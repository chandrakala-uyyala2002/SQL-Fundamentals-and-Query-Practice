# SQL Fundamentals and Query Practice

## Project Description
This project demonstrates SQL fundamentals using a
Student Database Management System.

## Topics Covered
1. SELECT and WHERE
2. ORDER BY
3. Primary Key and Foreign Key
4. INNER JOIN
5. LEFT JOIN
6. RIGHT JOIN
7. Subqueries
8. Aggregate Functions
9. GROUP BY and HAVING

## Tools Used
- MySQL
- SQL
- GitHub

## Database
Student Database Management System

## Objective
To practice SQL queries, retrieve data, filter records,
combine tables and perform data analysis.
